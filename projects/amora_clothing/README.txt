AMORA — XAMPP SETUP

1. Copy the entire amora_clothing folder into:
   C:\xampp\htdocs\

2. Start Apache and MySQL in XAMPP Control Panel.

3. Open phpMyAdmin:
   http://localhost/phpmyadmin

4. Click Import, choose database.sql, and run it.
   The script creates the database amora_fashion automatically.

5. Open:
   http://localhost/amora_clothing/

Database settings are in config.php. Default XAMPP MySQL is root with an empty password.

NOTE: Product/editorial images are loaded from Unsplash URLs, so internet access is needed for those images. The website itself runs locally in XAMPP.
